# Team-Arbeitsanweisung

Diese Datei ist die kurze Übergabe an das Team. Details und Akzeptanzkriterien
werden vor Ort besprochen.

## Grundauftrag

- Code lesen und nachvollziehen
- Projekt lokal nach `ANLEITUNG.md` starten
- Funktionen im Browser prüfen
- Tests lokal ausführen
- Auffälligkeiten notieren
- Änderungen nur auf eigenen Branches machen

## Zu prüfen

- Registrierung, Login und Logout
- Dashboard und Navigation
- Module und Vorlesungen
- Aufgaben
- Abgaben und Prüfungen
- Lernpläne
- Fortschritt
- Vollständige Kalenderansicht
- PDF-Unterlagen und Suche
- Nutzertrennung: Jeder Nutzer darf nur eigene Daten sehen
- Texte, Links und Buttons: nichts darf leer oder ohne Funktion sein

## Offene Pflichtpunkte

### Benachrichtigungsbutton

Oben rechts gibt es einen `!`-Button mit roter `3`. Der Button zeigt aktuell
nichts Sinnvolles an.

Aufgabe für das Team:

- Dynamische Anzahl statt fester `3`
- Beim Klick Hinweise anzeigen
- Sinnvolle Inhalte: überfällige Aufgaben, überfällige Termine, bald fällige Punkte

### Vollständige Kalenderansicht

Es gibt Kalenderdaten und eine Dashboard-Vorschau, aber noch keine vollständige
Kalenderseite für den Nutzer.

Aufgabe für das Team:

- Eigene Kalenderansicht bauen
- Vorlesungen, Aufgaben, Abgaben, Prüfungen und Lernpläne anzeigen
- Link vom Dashboard auf diese Ansicht setzen

### Mehr erfahren

Unten in der Sidebar gibt es den Link `Mehr erfahren`. Der Link führt aktuell nur
zurück zum Dashboard.

Aufgabe für das Team:

- Echte Hilfe-, Tutorial- oder Erste-Schritte-Seite bauen
- Link auf diese Seite setzen
- Später optional als interaktives Tutorial erweitern

## Mögliche spätere Erweiterungen

- Einmaliges Tutorial beim ersten Login
- Tutorial später erneut starten können
- Demo-Daten-Assistent
- Wiederkehrende Aufgaben und Termine
- Kalenderexport
- Tags für Aufgaben und Materialien
- PDF-Vorschau im Browser
- Bessere Lernstatistiken

## Rückmeldung

Nach der Prüfung soll das Team kurz melden:

- Was wurde getestet?
- Was funktioniert?
- Was ist kaputt oder unklar?
- Welche Tests wurden ausgeführt?
